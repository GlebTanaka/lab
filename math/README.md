# Mathematics Lab

Notes, exercises, and computational experiments for learning mathematics.
Python is a tool for exploring the subject, not the organizing topic.

## Learning Tracks

- [Konkrete Mathematik](konkrete-mathematik/README.md): following Edmund Weitz's
  *Konkrete Mathematik (nicht nur) fuer Informatiker*.

## Repository Layout

This directory is the `math/` subtree of `GlebTanaka/lab`. Its contents are also
published at the root of <https://github.com/GlebTanaka/lab-math>.

- In the lab checkout, open `math/` or an individual learning track in your IDE.
- In a standalone `lab-math` clone, open the repository root.
- Keep each track's environment and dependencies inside that track.

For subtree maintenance, use `GIT_WORKFLOW.md` at the root of the lab repository.
Do not create a nested Git repository inside `lab/math/`.

## Learning Approach

Read, attempt exercises independently, implement experiments, and explain the
results in your own words. Distinguish numerical evidence from a proof.
Record chapter and exercise references rather than copying book pages or the
publisher's solution material into this public repository.
